# Short URL App

A URL shortener application built using **Node.js**, **Express**, **MongoDB**, and **EJS**.

## Features
- Shorten long URLs to short, easy-to-share URLs.
- Track visit history for each shortened URL.
- **Stateful authentication** using cookies (session-like behavior).
- Users must sign up and log in to create and manage their URLs.

## Tech Stack
- Node.js
- Express
- MongoDB + Mongoose
- EJS
- Cookie-based stateful authentication

## How to Run
```bash
git clone https://github.com/VedantGitthub/short-url-app.git
cd short-url-app
npm install
npm start
