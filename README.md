# Short URL App (JWT Version)

A URL shortener application built using **Node.js**, **Express**, **MongoDB**, and **EJS**.

## ✨ Features
- Shorten long URLs to short, easy-to-share links.
- Track visit history (with timestamps) for each shortened URL.
- User signup and login with **JWT-based stateless authentication**.
- Users can create, view, and manage URLs tied to their account.

## 🛠 Tech Stack
- Node.js
- Express
- MongoDB + Mongoose
- EJS
- JSON Web Token (JWT) for stateless authentication

## 🚀 How to Run

```bash
git clone https://github.com/VedantGitthub/short-url-app.git
cd short-url-app
git checkout jwt-auth
npm install
npm start
